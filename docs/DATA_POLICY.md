# Data in this source edition

This copy excludes stored provider data, SQLite snapshots, notebook outputs,
historical charts and reports, credentials, and the original Git history.

The prices in `examples/offline_gold.py` are hand-built examples taken from
the project's test cases. They are synthetic, not observed market prices.

Optional workflows fetch data from external providers. Account access and
redistribution permissions have not been verified for this copy. Review the
applicable terms before publishing downloaded content or supplying client
deliverables. The MIT license covers original code, not third-party content.

Generated datasets and reports should remain local until their publication
has been reviewed. Ignore rules do not remove already committed files.
Inspect staged changes before pushing.

Keep API keys in an ignored `.env` file or environment variables.
